# Нотатки

Гілка feature/title призначена для оновлення назви проєкту.
Merge об'єднує гілки шляхом створення спеціального merge-коміту зі збереженням повної структури історії розгалуження.
Rebase переносить коміти поточної гілки поверх цільової, формуючи строго лінійну історію та змінюючи хеші перенесених комітів.
